Connect to GitHub

Save writes your changes to the GitHub repository that hosts your site. The live site updates about a minute later.

How do I get an access key?
  1. Open GitHub's new access token page.
  2. Name it Portfolio admin and pick an expiration. When it runs out, make a new one and paste it here.
  3. Under Repository access, choose Only select repositories and pick your site's repository.
  4. Under Permissions, add Contents and set it to Read and write.
  5. Click Generate token, copy it, and paste it above.

The key is kept only in this browser. Don't share it with anyone.
